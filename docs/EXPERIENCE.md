# 四套体验设计纲领

> 用户的要求：「把里面所有的元素都换一下，你现在只是换了简单的元素而已。
> 重新设计一套元素、或者交互逻辑或者什么的都要设计 ——
> 比如兄弟交互逻辑就很简单，姐妹就很女生感，宝宝就很浪漫。
> **要彻底贯穿，让不同的人有不同的体验。**」

---

## 一、核心洞察：**动效的长短本身就是性格**

这是整套设计的出发点。

同一颗按钮，做出 120ms 的动作和做出 420ms 带一点回弹的动作，
读起来是**两个完全不同的人**：

| 时长 | 读起来像 |
| --- | --- |
| 80~120ms，线性 | 「别磨叽，快点」 |
| 250~300ms，标准缓动 | 「嗯，我看看」 |
| 400~450ms，带过冲的回弹 | 「来嘛，不急～」 |

所以「换体验」的关键不是换颜色 ✗ ——
**几何 + 材质 + 动效节奏 + 交互逻辑 + 反馈方式 + 文案口吻**，六样一起换 ✓

（我第一版只换了字体和颜色，所以看起来还是同一个东西 ✓）

## 二、令牌：借 Material Design 3 的骨架

时长与缓动不自己拍脑袋 —— 用 [Material Design 3 的 motion tokens](https://m3.material.io/styles/motion/easing-and-duration/tokens-specs)
那套行业公认的档位，**但每个身份取不同的档**。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--dur-1` | 100ms | 微反馈（按下、悬停） |
| `--dur-2` | 200ms | 小元素进出 |
| `--dur-3` | 300ms | 卡片、面板 |
| `--dur-4` | 450ms | 大段叙事 |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 通用 |
| `--ease-decelerate` | `cubic-bezier(0, 0, 0, 1)` | 进场 |
| `--ease-accelerate` | `cubic-bezier(0.3, 0, 1, 1)` | 退场 |
| `--ease-emphasis` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 要有分量 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 回弹（宝宝专用） |

**每个身份重新定义这几个值**：

| | 好兄弟 | 好姐妹 | 好宝宝 | DAD&MUM |
| --- | --- | --- | --- | --- |
| `--dur-1` | 60ms | 120ms | 160ms | 50ms |
| `--dur-2` | 90ms | 200ms | 260ms | 70ms |
| `--dur-3` | 120ms | 300ms | 380ms | 90ms |
| `--dur-4` | 160ms | 420ms | 520ms | 110ms |
| `--ease` | `linear` | `decelerate` | `spring` | `linear` |
| 整体读起来 | **快、干脆** | **优雅、柔** | **慢、弹、甜** | **几乎不动** |

> 兄弟用 `linear` 而不是缓动：缓动是"有情绪"的，
> 而兄弟的人设就是**没情绪、直接办**。
> 家长用 `linear` 也是"没情绪"，但理由不同 —— 那是**公事公办**。

## 三、六个维度逐个身份对照

| 维度 | 好兄弟 | 好姐妹 | 好宝宝 | DAD&MUM |
| --- | --- | --- | --- | --- |
| **一句人设** | 别磨叽 | 要好看 | 来嘛不急 | 按流程办 |
| **几何** | 直角方形 | 圆角 / 椭圆 | 爱心 / 超圆 | 正圆 / 标准圆角 |
| **材质** | 牛皮纸、塑料卡 | 珠光、缎面 | 奶油、棉花糖 | 纸、钢印 |
| **装饰密度** | **零** | 中（缎带 + 珠光） | **最多**（爱心玫瑰星光） | 中，但全是正式图形 |
| **动效** | 快 + 线性 | 中 + 优雅 | 慢 + 回弹 | 极快 + 线性 |
| **步骤数** | **最少** | 中 | 多（有铺垫和告别） | 标准（像张表单） |
| **按钮动词** | 「行，就这么定」 | 「好呀～」 | 「好！我去！」 | 「同意」「不同意」 |
| **成功反馈** | 直接跳走，什么都不说 | 一道光扫过 | **撒花 + 弹跳** | 打勾 + 编号推进（第 3/6 项） |
| **失败/拒绝** | 一句「行吧」 | 温柔挽留 | 撒娇 / 哭 | 「不予受理」 |
| **交互动词** | 点、定 | 挑、试 | 缠、哄 | 填、报 |

## 五、怎么落地（工程上）

1. **令牌层**：`[data-theme='x']` 上定义 `--dur-*` / `--ease` ✓
   全站所有 `transition` / `animation` 都从令牌取值，**不写字面量** ✓
2. **几何层**：形状令牌（圆角、裁切）✓ 已有 `theme-shapes.css` ✓
3. **纹理层**：底纹与材质 ✓ 已有 `invite-page.css` 的四套材质 ✓
4. **行为层**：少数真正需要"逻辑不同"的地方用 JS 分支
   （步骤数、按钮文案、成功反馈类型）✓

**优先级**：令牌层 > 几何层 > 行为层。
前两层能覆盖 80% 的观感差异，而且**风险低**（纯 CSS，不动逻辑）。

## 六、已落地（都是实测出来的值，不是设计稿）

### 动效令牌

| | 翻页动效 | 时长 | 缓动 | 按钮按下 | 悬停抬升 |
| --- | --- | --- | --- | --- | --- |
| 好兄弟 | `step-none` 直接换 | **0.16s** | `linear` | 0.06s / 0.96 | 1px |
| 好姐妹 | `step-slide-x` 横滑 | 0.42s | 缓入 | 0.12s / 0.97 | 4px |
| 好宝宝 | `step-pop-up` 弹上来 | **0.52s** | **回弹** | 0.16s / **0.93** | 6px |
| DAD&MUM | `step-fade` 淡入 | **0.11s** | `linear` | 0.05s / 0.995 | 1px |

### 几何

印章：兄弟**正方形** ｜ 姐妹**椭圆** ｜ 宝宝**爱心形** ｜ 家人**正圆**
身份卡：`0 / 34 / 26 / 8 px`（+ 各自的投影性格）

### 行为

| | 步骤数 | 进度读法 | 回执 | 停留 |
| --- | --- | --- | --- | --- |
| 好兄弟 | **5 步**（少一步） | 「第 1 / 5 步」**没有那排点** | 「行，交上去了。」 | **420ms** |
| 好姐妹 | 6 步 | 小圆点 | 一道光扫过 | 900ms |
| 好宝宝 | 5 步 | **小爱心**（会心跳） | **撒花 + 弹跳** | **1600ms** |
| DAD&MUM | 5 步 | 小方块 + 「第 1 / 5 **项**」 | **打勾 + 编号** | 700ms |

邀请页的两个按钮：

| | 婉拒 | 接受 |
| --- | --- | --- |
| 好兄弟 | 不去 | **行，就这么定** |
| 好姐妹 | 那天不太行 | **好呀～** |
| 好宝宝 | 那天不行嘛 | **好！我去！** |
| DAD&MUM | 不同意 | **同意** |

> **动词就是人设。** 同一句「接受」，兄弟在拍板、宝宝在蹦、家人在盖章。

### 选中的那一刻

兄弟**没有动画**（选个日期要什么特效）／姐妹柔柔放大 ／宝宝**弹一下 + 冒一颗心** ／家人**一个勾**。

## 七、惊艳层：空气与光

### 问题出在哪

在这之前页面是「**静态的精美**」—— 材质、形状、排版都对，但
**空气是死的、光是平的**。所以看着精致，却不惊艳。

### 上网学到的（同类产品是这么做的）

找了两个同类产品的**源码**（都不是成品展示，能看见手法）：

| 项目 | 它怎么做的 |
| --- | --- |
| [lucianofedericopereira/my-wedding](https://github.com/lucianofedericopereira/my-wedding) | 「**纯 CSS 实现细腻的落花瓣效果**，不依赖任何第三方库」 |
| [junayed-hasan/valentines_blossoming_flower](https://github.com/junayed-hasan/valentines_blossoming_flower) | 「花卉动画 + **发光效果**」 |

**结论**：婚礼电子请柬这一类，几乎都用**纯 CSS 的飘落物 + 发光**。
和我们「不加动画库」的取向一致 —— 可以照做。

### 于是补了两层

**① 空气层**（`atmosphere.tsx` + `atmosphere.css`）
飘什么、飘多少，**也是性格**：

| | 飘什么 | 几粒 |
| --- | --- | --- |
| 好兄弟 | 只有几粒极淡的火星 | 8 |
| 好姐妹 | 珠光花瓣 + 细闪 | 12 |
| 好宝宝 | **爱心 + 花瓣 + 玫瑰 + 星光** | **18** |
| DAD&MUM | 极少的尘埃（正式场合不撒花） | 8 |

技术上：**只动 transform / opacity**（走合成层），九条轨道错开时长与延迟
（整齐下落是最假的），窄屏减半，`prefers-reduced-motion` 整层关掉。

**② 光**（`invite-wow.css`）
- 印章底下垫**辉光**（会呼吸），不再像"贴上去的"
- 标题/时间地点换成**强烫金**：`background-size: 260%` + 反光真的扫过去
  （兄弟那套不用烫金 —— 它的人设不需要闪的东西）
- 信纸**四层叠影**做出厚度 + 边缘压一道暗（像被手指捏过）
- 火漆上**挂一滴蜡**，会缓慢往下坠

**③ 答应的那一下：满屏爆发**
前面那么长的铺垫就是为了这一下，所以它得真的炸：

| | 爆什么 |
| --- | --- |
| 好兄弟 | 10 道**火花**（尖的、短促） |
| 好姐妹 | 16 颗**珠光**（飘得久） |
| 好宝宝 | **26 片**花瓣 + 爱心 + 星光（最密最久） |
| DAD&MUM | **不撒花 —— 盖一个方正的红印压下来** |

只在「没回应 → 接受」那一下放，回头再看不重播（否则就成了噪音）。
