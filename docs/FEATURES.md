## 手机端健壮性

这一节的每一条都是**真实事故换来的**，不是在防假想敌。

- [x] **所有 localStorage 读写走 `safeStorage`**：手机浏览器里它会**直接抛异常**
      （微信内置浏览器、无痕模式、用户禁用存储、配额满），不是优雅地返回 null。
      以前 `getDeviceId()` 没兜住 —— 入口页正常（不碰存储），一点进「选日期」就**整页白屏**。
      好友只会以为链接坏了。现在拿不到就当「这台设备没有存储」，功能降级但不崩
- [x] **`crypto.randomUUID` 有退路**：iOS 15.4 以下的 Safari / 微信内置浏览器里没有这个函数，
      直接调会抛「not a function」。退回时间戳 + 随机数（这个 id 只是认人用的，不需要密码学强度）
- [x] **React 错误边界**：渲染时任何一次异常，默认结果是整棵树卸载 → 一片白屏。
      现在至少能看到「页面出了点问题 + 刷新」，技术细节进控制台
- [x] **`index.html` 里放静态兜底**：JS 文件加载失败时（网络断、隧道挂、网关 502）
      显示「正在打开… 要是停在这儿不动，下拉刷新一下」，而不是一整片空白
- [x] **接口挂掉时不给好友看开发者的话**：以前会显示「后端起了吗？本地开发要先跑 pnpm dev」，
      好友看到只会以为自己操作错了。现在是「暂时连不上，下拉刷新一下试试」

## 部署与运维

- [x] **`docker compose` 一条命令起停**，数据在独立的数据卷里；`down -v` 才真的删干净
- [x] **镜像内置日志轮转**（`max-size 5m` × 3）：Docker 默认**不限制日志大小**，
      长期跑会把磁盘写满
- [x] **容器里默认打开 `TRUST_PROXY`**：不开的话请求源 IP 全是 Docker 网关，
      **所有好友在限流眼里是同一个人**，一个人刷几条就把大家全挡了
- [x] **`start.cmd` / `stop.cmd`**：双击就起 / 停，自动找 cloudflared、打印公网地址和后台口令。
      `.cmd` 保持**纯 ASCII**（cmd.exe 按系统 ANSI 读批处理，UTF-8 中文会乱码并拆坏行），
      中文全放带 BOM 的 `.ps1` 里
- [x] **命名隧道优先**：`~/.cloudflared/config.yml` 存在就用它 —— 地址是**固定域名**；
      没有才退回快速隧道（地址随机、重启就变）
- [x] **`scripts/sandbox.mjs`**：不装 Docker 也能起一个「删掉就干净」的演练环境
      （换端口 + 换数据目录，不复制代码）
- [x] **三份部署文档**：`PUBLISH.md`（两条路怎么选 / 口令在哪找 / 验收清单）、
      `DEPLOY.md`（服务器十步）、`TUNNEL.md`（隧道，含每一步的验证命令）

## 安全
